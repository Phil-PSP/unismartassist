  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

ISSUE 1: "I don't see EXAMINATION SYSTEM section"

Solution A: Clear Browser Cache
→ Press Ctrl+Shift+Delete
→ Clear cache and cookies
→ Close browser completely
→ Reopen and try again

Solution B: Hard Refresh
→ Press Ctrl+F5 (Windows)
→ Or Cmd+Shift+R (Mac)

Solution C: Try Different Browser
→ Open Chrome/Firefox/Edge
→ Go to admin URL
→ Login again

Solution D: Use Direct Link
→ Go to: http://127.0.0.1:8000/admin/exams/exam/
→ This bypasses the sidebar

ISSUE 2: "I see 'Exams' but it's empty"

Solution: Check if you're logged in as admin
→ Top right corner should show "ADM/001"
→ If it shows "STU/..." you're logged in as student
→ Logout and login as admin

ISSUE 3: "Page says 'Permission Denied'"

Solution: Verify admin permissions
→ Logout completely
→ Login with: ADM/001 / admin123
→ Check user role is 'admin'
