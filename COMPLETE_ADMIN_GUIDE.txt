  2. HOW TO UPLOAD QUESTIONS (4 METHODS)
═══════════════════════════════════════════════════════════════

METHOD 1: Django Admin Panel (Manual)
────────────────────────────────────
Best for: 1-10 questions, full control

Steps:
1. Go to /admin/
2. Click "EXAMINATION SYSTEM" → "Exams"
3. Add or edit exam
4. Scroll to "Questions" section
5. Click "Add another Question"
6. Fill in question details
7. Add options (for multiple choice)
8. Mark correct answer
9. Save

METHOD 2: Bulk CSV Upload (Recommended)
────────────────────────────────────────
Best for: 10-200 questions, Excel users

Steps:
1. Go to /exams/questions/bulk-upload/
2. Download CSV template
3. Open in Excel/Google Sheets
4. Fill in questions:
   - question_text: Your question
   - question_type: multiple_choice, true_false, fill_blank
   - marks: Points (1, 2, 5, etc.)
   - options: A|B|C|D (separated by |)
   - correct_answers: 0 (index of correct option)
5. Save as CSV
6. Upload file
7. Select exam
8. Click "Upload Questions"

Example CSV:
question_text,question_type,marks,order,options,correct_answers
"What is 2+2?",multiple_choice,1,1,"2|3|4|5",2
"Python is easy.",true_false,1,2,"True|False",0
"Capital is _____.",fill_blank,1,3,,,Paris

METHOD 3: Bulk JSON Upload
───────────────────────────
Best for: Developers, programmatic generation

Steps:
1. Go to /exams/questions/bulk-upload/
2. Download JSON template
3. Create JSON file with questions
4. Upload file
5. Select exam
6. Click "Upload Questions"

METHOD 4: AI Generation (Fastest!)
──────────────────────────────────
Best for: Quick exam creation, any topic

Steps:
1. Go to /exams/ai/generate/
2. Enter topic (e.g., "Python Programming")
3. Set number of questions (1-200)
4. Choose difficulty (easy/medium/hard)
5. Select question types
6. Click "Generate Exam with AI"
7. Done! Exam is ready immediately

  3. HOW TO CREATE EXAMS
═══════════════════════════════════════════════════════════════

OPTION A: Manual Creation
─────────────────────────
1. Go to /admin/
2. Click "Exams" → "Add Exam"
3. Fill in:
   - Title
   - Course
   - Exam type (quiz, mid-sem, final)
   - Difficulty
   - Duration (minutes)
   - Total marks
   - Pass mark
4. Add questions (see Method 1 above)
5. Check "Is published"
6. Save

OPTION B: AI Generation
───────────────────────
1. Go to /exams/ai/generate/
2. Enter topic
3. Set parameters
4. Click "Generate"
5. Exam created automatically with questions!

  4. HOW TO MANAGE STUDENTS
═══════════════════════════════════════════════════════════════

View Student Attempts:
1. Go to /admin/
2. Click "Exam Attempts"
3. See all student submissions
4. Filter by exam, student, status
5. View scores and answers

Grade Manual Questions:
1. Go to /admin/ → "Exam Attempts"
2. Click on attempt
3. Scroll to answers
4. For short_answer/essay questions:
   - Read student's answer
   - Enter marks awarded
   - Add feedback
5. Save

View Analytics:
1. Go to /admin/ → "Exams"
2. Click on exam
3. See:
   - Number of attempts
   - Average score
   - Pass rate

  QUESTION TYPES
═══════════════════════════════════════════════════════════════

1. multiple_choice
   - 4 options (A, B, C, D)
   - 1 correct answer
   - AUTO-GRADED ✅

2. true_false
   - 2 options (True/False)
   - AUTO-GRADED ✅

3. fill_blank
   - Text input field
   - Case-insensitive matching
   - AUTO-GRADED ✅

4. short_answer
   - Text area
   - MANUAL GRADING REQUIRED ⚠️

5. essay
   - Large text area
   - MANUAL GRADING REQUIRED ⚠️

═══════════════════════════════════════════════════════════════
  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: Can't see exams in admin
Solution: Check "EXAMINATION SYSTEM" section, not "Exams" app

Problem: CSV upload fails
Solution: Check file format, use template, verify commas

Problem: Questions not auto-grading
Solution: Ensure question_type is multiple_choice, true_false, or fill_blank

Problem: Students can't access exam
Solution: Check "is_published" and "is_active" are checked

Problem: AI generation fails
Solution: Check Gemini API key in .env file
