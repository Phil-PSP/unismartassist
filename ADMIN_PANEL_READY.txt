  IF YOU DON'T SEE IT
═══════════════════════════════════════════════════════════════

TRY THIS (in order):

1. HARD REFRESH
   → Press Ctrl+F5 (Windows) or Cmd+Shift+R (Mac)
   → This forces browser to reload everything

2. CLEAR CACHE
   → Press Ctrl+Shift+Delete
   → Clear "Cached images and files"
   → Clear "Cookies and other site data"
   → Close browser completely
   → Reopen and try again

3. INCOGNITO MODE
   → Open new incognito/private window
   → Go to http://127.0.0.1:8000/admin/
   → Login as ADM/001
   → Check if you see "EXAMINATION SYSTEM"

4. DIFFERENT BROWSER
   → Try Chrome, Firefox, or Edge
   → Sometimes one browser caches differently

5. USE DIRECT LINK
   → Go to: http://127.0.0.1:8000/admin/exams/exam/
   → This bypasses the sidebar completely
   → You'll go straight to exam list
